# Tutoring_Information_Management_System
=======
# 家教信息筛选排序系统

一个基于 Python 的家教信息筛选与排序工具：根据「屏蔽词」过滤不符合要求的家教，再按「个人信息」匹配度降序排序，最终结果保存到 `res.txt`。同时提供命令行交互和可视化 Web 界面两种使用方式。

## ✨ 功能特性

- 🔍 **屏蔽词过滤**：自动剔除包含任意屏蔽词的家教信息
- 📊 **匹配度排序**：按家教信息与个人需求的匹配次数从高到低排序
- 💾 **结果持久化**：排序结果自动保存到 `res.txt`
- ✏️ **文件管理**：支持查看、重置（清空）、新增三类 txt 文件
- 🌐 **可视化界面**：纯前端 HTML 界面 + 本地 HTTP 服务，无需安装第三方依赖

## 📁 目录结构

```
├── teaching.py          # 核心逻辑（读取 / 过滤 / 排序 / 修改）
├── server.py            # 本地 Web 服务端（Python 标准库，提供 JSON 接口）
├── index.html           # 前端界面（单文件，内联 CSS/JS）
├── Blocked_words.txt    # 屏蔽词（每行用「、」或换行分隔）
├── Personal_info.txt    # 个人信息（每行「键：值」格式）
├── Tutor_info.txt       # 家教信息（每条之间用空行分隔）
└── res.txt              # 排序结果（程序运行后自动生成）
```

## 🚀 快速开始

### 环境要求

- Python 3.6+（仅使用标准库，无需安装任何第三方包）

### 方式一：命令行使用

1. 准备好三个数据文件（`Blocked_words.txt`、`Personal_info.txt`、`Tutor_info.txt`），与 `teaching.py` 放在同一目录。
2. 运行：

```bash
python teaching.py
```

3. 按提示操作：

| 输入 | 含义 |
|------|------|
| `0` | 不需要修改，直接执行筛选排序并退出 |
| `1` | 修改文件（可选择重置 / 新增） |
| `3` | 查看文件内容 |
| `finish` | 结束修改任务并执行筛选排序 |

### 方式二：Web 界面使用

1. 将 `server.py`、`index.html` 与数据文件、`teaching.py` 放在同一目录。
2. 启动本地服务：

```bash
python server.py
```

3. 浏览器打开 **http://127.0.0.1:8000**（注意：不要直接双击 `index.html`，必须通过服务器地址访问）。

## 📄 数据文件格式

### Blocked_words.txt（屏蔽词）

每行一个或多个屏蔽词，多个词用中文顿号 `、` 分隔：

```
网课
线上、远程
```

### Personal_info.txt（个人信息）

每行一条，格式为 `键：值`（冒号为中文全角冒号 `：`）：

```
科目：数学
年级：初三
上课方式：线下
```

### Tutor_info.txt（家教信息）

每条家教信息之间用**空行**分隔，内容自由填写：

```
张老师，教初中数学，可线下授课，有 5 年经验

李老师，教高中物理，仅线上授课
```

## 🔌 服务端 API 说明

| 方法 | 路径 | 参数 | 说明 |
|------|------|------|------|
| GET | `/api/view` | `?file=文件名` | 查看文件内容 |
| POST | `/api/reset` | `{"file": "文件名"}` | 清空文件 |
| POST | `/api/append` | `{"file": "文件名", "content": "内容"}` | 向文件末尾追加内容 |
| POST | `/api/run` | — | 执行筛选排序并返回结果 |

可用文件名为：`Blocked_words.txt`、`Personal_info.txt`、`Tutor_info.txt`、`res.txt`。

## 🛠 常见问题

**Q：Web 界面提示「请求失败，请确认服务已启动」？**

1. 确认是通过 `http://127.0.0.1:8000` 访问，而不是双击打开 `index.html`；
2. 确认 `python server.py` 已成功启动（看到「✅ 服务已启动」）；
3. 端口被占用时，修改 `server.py` 末尾的 `port = 8000` 为其他端口。

**Q：找不到 txt 文件？**

确认数据文件与 `.py` 脚本在**同一目录**下运行，文件名需完全一致。
